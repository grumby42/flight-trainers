Why some features need HTTPS

Phone motion sensors (tilt, magnetometer), live weather, and barometric altitude only work when a page is served over a secure context — HTTPS or localhost. Opened straight from a downloaded file (file:///), the browser silently blocks them. Hosting these on GitHub Pages serves them over HTTPS and turns all of that on.

Conceptual teaching models — not flight simulators. Use the POH/AFM & ACS for real numbers. github.com/grumby42
